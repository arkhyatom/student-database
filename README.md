# Student Database Management System

A simple command-line student database using Python and SQLite.

## Features
- Add, view, search, and delete students
- View passing students (grade >= 70)
- Calculate average grade

## Technologies
- Python 3
- SQLite (built-in `sqlite3` module)

## How to Run
1. Clone this repository
2. Run `python main.py`
3. Follow the menu options

## Menu Options
1. Add student
2. View all students
3. View passing students
4. Show average grade
5. Search student
6. Delete student
7. Exit
